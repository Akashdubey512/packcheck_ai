1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
PackCheck AI is an enterprise-grade automated regulatory compliance inspection 
platform designed for Legal Metrology enforcement officers, packaging manufacturers,
and e-commerce platforms across India. 

The platform inspects packaged commodity labels against the statutory mandates 
of the Legal Metrology (Packaged Commodities) Rules, 2011 (including the 2017, 
2021, and 2022 Gazette amendments).

The system consists of a 3-tier microservices architecture:
1. AI / ML Computer Vision Microservice (`ai-service`):
   Python 3.11/3.13 + FastAPI + RapidOCR (ONNX PP-OCRv3) / EasyOCR / PyTesseract
   + Multi-View Spatial Fusion + Platt-Calibrated Confidence + SHA-256 Provenance.
2. Core Integration Backend (`backend`):
   Node.js + Express + MongoDB + JWT Auth + Multer + Puppeteer PDF Generation.
3. Regulatory Inspection Web Application (`frontend`):
   React 18 + Vite + TypeScript + TailwindCSS + TanStack Query + Framer Motion
   + 11 Specialized Operator Views + Resilient Zero-Dependency Offline Demo Engine.
4. Total Verification Metric:
   173 automated tests passing at 100% across the frontend and AI services.

3. COMPONENT-BY-COMPONENT AUDIT & FEATURES
--------------------------------------------------------------------------------

3.1 AI / Computer Vision Microservice (`ai-service`)
--------------------------------------------------------------------------------
Framework      : FastAPI 0.141+ with ASGI Uvicorn
Language       : Python 3.13 / 3.11
Test Status    : 106 Tests Passed (100.0%) in 4.85 seconds
Primary Routes :
  - GET  /                           : Interactive Dark-Mode Auditor UI Dashboard
  - GET  /health                     : Service liveness probe ({"status": "HEALTHY"})
  - GET  /ready                      : Pipeline readiness probe ({"status": "READY"})
  - POST /api/v1/inspect             : Multi-view packaging inspection (Multipart)
  - POST /api/v1/review              : Officer human override with audit trail
  - GET  /api/v1/report/pdf/{id}     : Regulatory PDF report generation
  - POST /analyze                    : Backwards-compatible adapter for Node backend

Subsystem Breakdown:
1. Security & Guardrails (ml/security/upload_validator.py):
   - Magic byte header inspection (validates true JPEG, PNG, WEBP).
   - Decompression bomb guard: rejects images exceeding 50 Megapixels.
   - Strict 20MB payload ceiling.
   - Path traversal sanitization preventing arbitrary directory write.

2. Preprocessing & Quality (ml/preprocessing/):
   - Laplacian variance blur estimator: grades GOOD, ACCEPTABLE, POOR, UNUSABLE.
   - Hough transform skew detection with automatic rotation compensation.
   - 4-quadrant orientation detector (0, 90, 180, 270 deg) & upright rotation.
   - 4-point quadrilateral perspective warp for angled packaging.

3. OCR Ensemble Subsystem (ml/ocr/):
   - Primary engine: RapidOCR (ONNX PP-OCRv3) for real-time CPU performance.
   - Secondary fallbacks: EasyOCR and PyTesseract.
   - Spatial reading-order organizer: sorts bounding boxes top-to-bottom.
   - Region merger: combines adjacent single-line boxes into unified sentences.
   - Statutory character normalizer: fixes OCR confusion (e.g. Rs./₹, g/ml).

4. Multi-View Packaging Fusion (ml/inspection/cross_view_fusion.py):
   - Supports ingesting multiple package faces (Front, Back, Side, Top, Bottom).
   - Resolves cross-view candidate consensus.
   - Inter-panel contradiction detector: flags conflicting declarations 
     (e.g., MRP stamped on front does not match barcode panel on back).

5. Confidence, Evidence & Provenance (ml/confidence/):
   - Platt-calibrated probability scoring for every declaration.
   - Visual evidence bounding-box cropping with coordinate retention.
   - 64-hex character SHA-256 provenance hash generated for every fact/verdict.

6. Reporting & Human Review (reporting/pdf_exporter.py & app/services/):
   - ReportLab generation of official Legal Metrology certificates.
   - Immutable audit trail tracking officer overrides, timestamps, and roles.

6. SECURITY, DATA GOVERNANCE & PROVENANCE LEDGER
--------------------------------------------------------------------------------
1. File Upload Safeguards:
   - Max 20MB file size limit enforced at middleware and application layers.
   - Decompression bomb guard stops memory exhaustion from high-resolution inputs.
   - Magic bytes inspection ensures file extension cannot spoof payload type.

2. Cryptographic Provenance:
   - Every extracted declaration is bound to an immutable SHA-256 hash.
   - Legal rule evaluation decisions are hashed alongside raw OCR evidence.
   - Creates court-admissible forensic audit records for Legal Metrology officers.

3. Repository & Data Hygiene:
   - Over 5.5 GB of heavy training sets, raw images, and virtual environment 
     files are excluded via an enterprise .gitignore.
   - Zero sensitive secrets or .env credentials are exposed.
   - Commit history is clean and lightweight (< 2MB delta).
